# Historical Design and Plan Records

The `specs/` and `plans/` directories preserve date-stamped design decisions
and implementation intent. They are historical records, not current setup
instructions, release status, or proof that a feature is present or absent.

When a record differs from the current checkout, use source, tests,
[`../architecture.md`](../architecture.md), and the relevant package README as
the authority. Do not rewrite old records merely to make their original plan
match later implementation; add a new dated record for a new design decision.
